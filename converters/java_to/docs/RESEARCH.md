# 調査メモ / Research (2000–2026)
## 年代別 / By era
- 2000前後: Servlet/JSP、Struts 1、Tapestry、JDBC、EJB。 2002–2006: Spring、Hibernate、MyBatis、JSF、Struts 2、Wicket、Stripes、Seasar2(日本)、GWT。
- 2007–2012: Play、Grails、Spring Roo、Vaadin、JAX-RS(Jersey/RESTEasy)、Vert.x、Spark、Dropwizard。
- 2014–2019: Spring Boot、Ratpack、Jooby、Armeria、gRPC、MicroProfile、Spring WebFlux、Javalin、Micronaut、Helidon、Quarkus、Jakarta EE(jakarta.*)。
- 実際の一覧と判定根拠は `src/frameworks.rs`(`java_to frameworks`)。
## 似たツール / Similar tools
- 自前の兄弟: COBOL_to(COBOL→4出力)、2FastAPI・2MFastAPI・2Poem(Python→…)。Java 専用で FastAPI/Poem へ向かう公開ツールは調べた範囲で見つからなかった(未検証・網羅ではない)。
- 一般の言語間変換(例: Java→Kotlin の IDE 機能、Java→C# の商用変換)はあるが、Web ルートを Python/Rust のフレームワークへ写す目的のものとは別物。
## 注意 / Caveat
公開年は概数、各項目の一次資料URLはこのメモに載せていない。必要になった時点で確認する。

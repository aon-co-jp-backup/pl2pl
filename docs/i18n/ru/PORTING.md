# pl2pl — передача дел
(Прежние подробные записи — в `docs/HISTORY-ja.md`, на японском.)

## Где мы сейчас (2026-11-19)
- Выпущена версия 0.1.0 с установщиками для Windows, Linux и Mac и тестами в CI.
- PHP → FastAPI проверен сквозным тестом на настоящем FastAPI (49 проверок): маршруты, Eloquent, построитель запросов, Blade, middleware, связи.
- `pl2pl web` теперь тоже распознаёт PHP и передаёт его дальше.
- Новое: `pl2pl watch` находит новые версии, тестирует, исправляет, а если ничего не вышло — уведомляет. В version-control добавлена опция `--notify-file`.
- COBOL_to и Java_to включены в `converters/`.

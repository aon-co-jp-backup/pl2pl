# Передача дел pl2pl
## Состояние (2026-11-19)
v0.1.0 опубликована (установщики Windows/Linux/macOS, сквозные тесты в CI). Конвертация PHP охватывает маршруты, многооператорные тела, Eloquent (SQLAlchemy), query builder с пагинацией, связи, Blade (Jinja2) и middleware (`Depends`); всё протестировано сквозным образом. Numba, Kokkos (Serial) и `pl2pl web` подтверждены реальными запусками.
## Нерешённое (по приоритету)
1. PHP: вложенный `with`, `morph`, `cursorPaginate`, компоненты/стеки/авторизация Blade, middleware после `$next`.
2. Включить COBOL_to / Java_to в pl2pl, затем удалить исходные репозитории (сначала подтвердить; необратимо; над ними работают другие сессии).
3. Прототип общего IR.
4. Интеграция с aruaru-llm (реальная установка `llm setup` не проверена).
5. Kokkos на GPU / `Kokkos::View`; ядра на open-cuda / open-directx.
6. Владелец пишет `docs/DESIGN.md`; проверить актуальность `docs/LANGUAGES.md`.
7. Запустить новые примеры PHP в CI на Linux arm64 и macOS.
## Тесты
`bash tests/run-all.sh` (WSL), `bash tests/run-php.sh` (PHP сквозной), `cargo test --release`.

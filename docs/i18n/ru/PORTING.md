# pl2pl: передача дел
## Текущее состояние (2026-11-19)
Версия 0.1.0 выпущена: есть установщики для Windows, Linux и macOS и сквозные тесты в CI. Преобразование PHP охватывает маршруты, тела из нескольких операторов, Eloquent (SQLAlchemy), конструктор запросов с пагинацией, связи (включая вложенный `with`), Blade (Jinja2) и middleware (`Depends`) — всё проверено сквозными тестами. Numba, Kokkos (Serial) и `pl2pl web` подтверждены реальными запусками.
## Что осталось, по приоритету
1. PHP: авторизация `@can` и классовые компоненты Blade, middleware, меняющий тело ответа после `$next`.
2. Влить COBOL_to / Java_to в pl2pl, затем удалить исходные репозитории (сначала подтвердить; необратимо; над ними работают другие сессии).
3. Прототип общего промежуточного представления.
4. Интеграция с aruaru-llm (реальная установка через `llm setup` пока не проверена).
5. Kokkos на GPU / `Kokkos::View`; ядра на open-cuda / open-directx.
6. Владелец пишет `docs/DESIGN.md`; проверить, что `docs/LANGUAGES.md` актуален.
## Тесты
`bash tests/run-all.sh` (WSL), `bash tests/run-php.sh` (PHP, сквозной), `cargo test --release`.

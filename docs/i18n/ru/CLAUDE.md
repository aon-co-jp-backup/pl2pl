# pl2pl — заметки для разработки
- **Задача**: инструмент, который переписывает код между языками, фреймворками и операционными системами (написан на Rust, лежит в `src/`). Исходные языки перечислены в `docs/LANGUAGES.md`, сочетания — в `docs/COMBINATIONS.md`. Проект владелец понемногу пишет в `docs/DESIGN.md`. **Никогда не придумывайте спецификацию за него.**
- **Направление**: переписывать «многие во многие» между известными языками. Не строить всё сразу, а начинать с выбранного. На сайте только инструкции и загрузка. Переписывание выполняется в приложении для ПК.
- **Правила**: то, что нельзя переписать, остаётся как `TODO` и попадает в отчёт (никогда не прятать). Действовать осторожно (если возможны зависимости или побочные эффекты — ничего не менять). Прежде чем сказать «готово», запустить по-настоящему. Новых REST не делать. Отвечать только по-японски.
- **Общий вид (IR)**: `src/ir.rs`. Входная сторона (PHP, Python, Java) и выходная (JSON, OpenAPI, FastAPI) разделены, чтобы новые пары добавлялись легко. Файлы, где маршруты не найдены, попадают в отчёт. Вывод нужно проверять по-настоящему, например через `py_compile`.
- **PHP**: `src/php.rs`, `src/blade.rs`, `src/middleware.rs`. Сквозной тест: `tests/run-php.sh` (настоящие FastAPI, SQLite, Jinja2). Модульные тесты: `cargo test --release`. В WSL: `wsl -d Ubuntu -- bash <файл>`.
- **Автоматическое слежение за версиями**: `pl2pl watch` (`src/watch.rs`, `registry/ecosystem.toml`). Записи без команды проверки только показываются как «не проверено» и сами никогда не обновляются. Оповещения идут через `--notify-file` в version-control.
- **Развёртывание**: страница-визитка — `webpage/index.html`. На VPS: `/root/easy-web.tokyo/pl2pl` (обновляется через `git pull`; страница статическая, перезапуск не нужен), `pl2pl-web.service` на порту 8142, уже добавлен в `domains.toml`.
- **Подводные камни**: файлы с японским текстом писать через Python `-X utf8`. Shell-скрипты держать с LF. Git Bash переписывает пути `/mnt/...`. Для текста со множеством кавычек или `\` использовать инструменты Write / Edit, а не heredoc.
- **COBOL_to / Java_to**: уже включены в `converters/`. Удаление исходных репозиториев необратимо — сначала получить окончательное согласие.
- **Система перевода** (человеческий язык) отделена от конвертеров. Конвертеры не опираются на LLM.
- **Языки документации**: японские файлы — оригиналы. Английские файлы переписаны простыми словами. Остальные языки в `docs/i18n/` — машинный перевод (носители языка пока не проверяли). Более ранняя история: `docs/HISTORY-ja.md`.

# Заметки по разработке pl2pl
- Роль: конвертер между языками/фреймворками/ОС (Rust CLI, `src/`). Кандидаты в источники: `docs/LANGUAGES.md`; комбинации: `docs/COMBINATIONS.md`. Спецификацию понемногу пишет владелец в `docs/DESIGN.md`; не придумывать спецификацию за него.
- Правила: неконвертируемое остаётся как `TODO` и попадает в отчёт; никогда не отбрасывать молча. Перед сообщением о завершении проверять реальным запуском. Решения осторожные (не конвертировать при возможной зависимости или побочном эффекте).
- PHP: `src/php.rs`, `src/blade.rs`, `src/middleware.rs`; сквозной тест `tests/run-php.sh` (настоящие FastAPI, SQLite, Jinja2), модульные тесты `cargo test --release`. Запуск из WSL: `wsl -d Ubuntu -- bash <файл скрипта>`.
- Подводные камни: в Windows файлы с японским текстом писать через Python `-X utf8`; shell-скрипты хранить с LF; Git Bash переписывает пути `/mnt/...`.
- COBOL_to и Java_to развивает другая сессия; включить позже, исходные репозитории удалять только после окончательного подтверждения (необратимо).
- Система перевода (естественный язык) отделена от конвертеров.
- Языки документации: японский (корень) и 9 языков в `docs/i18n/` (переводы ИИ, носителями языка не проверены).

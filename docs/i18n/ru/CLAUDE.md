# pl2pl CLAUDE
- **Роль**: конвертер между языками, фреймворками и операционными системами (программа на Rust для командной строки, каталог `src/`). Возможные источники перечислены в `docs/LANGUAGES.md`, комбинации — в `docs/COMBINATIONS.md`. Спецификацию понемногу пишет владелец в `docs/DESIGN.md`; не выдумывай спецификацию за него.
- **Правила**: то, что нельзя преобразовать, остаётся как `TODO` и попадает в отчёт — никогда не отбрасывай это молча. Прежде чем сказать, что задача выполнена, запусти всё по-настоящему. Оставайся осторожным: если возможны зависимости или побочные эффекты, не преобразуй.
- **PHP**: `src/php.rs`, `src/blade.rs`, `src/middleware.rs`. Сквозной тест — `tests/run-php.sh` (настоящие FastAPI, SQLite, Jinja2). Модульные тесты — `cargo test --release`. Запуск из WSL: `wsl -d Ubuntu -- bash <файл скрипта>`.
- **Подводные камни**: в Windows файлы с японским текстом записывай через Python с `-X utf8`; скрипты shell храни с окончаниями строк LF; Git Bash переписывает пути `/mnt/...`.
- **COBOL_to / Java_to**: ими занимаются другие сессии. Влить позже, а исходные репозитории удалять только после окончательного подтверждения — это необратимо.
- **Система перевода** (естественный язык): остаётся отдельно от конвертеров.
- **Языки документации**: японский в корне и ещё девять языков в `docs/i18n/` (переводы ИИ, носителями языка пока не проверены). Если меняется японский оригинал, обновляй и переводы.

# pl2pl

## Что такое pl2pl?
Программы пишут на разных «языках» (языках программирования).
**pl2pl — это инструмент, который переписывает программу с одного языка на другой.**
Например, он может превратить сайт на PHP (Laravel) в сайт на Python (FastAPI).
Работает в Windows, Linux и Mac (версия 0.1.0, ещё в разработке).

- Его устанавливают на свой компьютер. На сайте есть только инструкции и загрузка → <https://easy-web.tokyo/pl2pl/>
- Если pl2pl не может что-то переписать, он это не прячет. Он оставляет `TODO` (пометку «сделать позже») и объясняет причину в отчёте.
- Наша цель — чтобы можно было переписывать между как можно большим числом известных языков.

## Что он умеет сейчас
| Команда | Что делает |
|---|---|
| `pl2pl php` | PHP (Laravel / Symfony) → FastAPI. Подробнее в [PHP.md](../../PHP.md) (на японском) |
| `pl2pl web` | Смотрит в папку, узнаёт Java, COBOL, PHP и Flask/Django и передаёт каждое подходящему инструменту |
| `pl2pl ir` | (пробная версия) Приводит «маршруты» PHP, Python и Java к одному виду и делает из них JSON, OpenAPI или заготовку FastAPI |
| `pl2pl watch` | Находит новые версии языков и инструментов и сам подстраивается под них |
| `pl2pl cobol` | COBOL + JCL → GnuCOBOL (Linux) |
| `pl2pl omp` / `kokkos` / `gpu` | Ускоряет циклы C/C++ (gpu — пробная версия) |
| `pl2pl cport` | Делает так, чтобы C-код для UNIX работал и в Windows, и в Linux |
| `pl2pl pyhpc` | Ускоряет вычисления на Python с помощью Numba |
| `pl2pl llm setup` | Устанавливает ИИ-помощника (aruaru-llm). Настоящую установку мы ещё не проверяли |

## Как он сам подстраивается под новые версии
Мы запускаем `pl2pl watch` каждый вечер и каждое утро.
1. Он проверяет, не вышли ли новые версии языков и инструментов (список — в `registry/ecosystem.toml`).
2. Он проверяет работу на новой версии. Если тесты проходят, он сам обновляет «поддерживаемую версию».
3. Если не проходят, version-control (с помощью ИИ) пытается всё исправить.
4. Если и это не помогло, он отправляет сообщение на сохранённые адреса электронной почты и в LINE.

Обратите внимание: для laravel, symfony, flask, django и некоторых других он пока лишь сообщает: «вышла новая версия».
На GitHub тесты с самыми новыми версиями тоже сами запускаются каждый вечер и каждое утро.

## Как пользоваться
```
pl2pl php ./myapp --out ./out
pl2pl web ./project --target fastapi --out ./out
pl2pl ir ./project --out ./out --format openapi
```

## Полезно знать
- pl2pl действует осторожно. Если что-то выглядит рискованным, он оставляет это как есть и объясняет почему. Скорость мы обещать не можем.
- Мы проверяли только небольшие примеры. Большие настоящие программы мы ещё не пробовали.

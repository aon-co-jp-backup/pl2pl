# pl2pl

**pl2pl превращает код, написанный на одном языке программирования или фреймворке, в код на другом.**
Например, сайт на PHP (Laravel) можно превратить в сайт на Python (FastAPI). Работает в Windows, Linux и Mac (v0.1.0, в разработке).

- Преобразование выполняется в приложении, которое вы устанавливаете на свой компьютер (программа командной строки). На сайте — только инструкции и загрузка.
- То, что нельзя преобразовать, не удаляется молча: pl2pl оставляет `TODO` и объясняет причину в отчёте.
- Цель — чтобы известные языки и фреймворки можно было преобразовывать друг в друга в как можно большем числе сочетаний.

## Что уже работает
| Команда | Что делает |
|---|---|
| `pl2pl php` | PHP (Laravel / Symfony) → FastAPI. Подробности: [PHP.md](../../PHP.md) (на японском) |
| `pl2pl web` | Просматривает папку, сам определяет Java, COBOL, PHP и Flask/Django и передаёт каждое подходящему конвертеру |
| `pl2pl cobol` | COBOL + JCL → GnuCOBOL (Linux) |
| `pl2pl omp` / `kokkos` / `gpu` | Переписывает циклы C/C++ под OpenMP, Kokkos или GPU (gpu — прототип) |
| `pl2pl cport` | Делает так, чтобы C-код для UNIX работал и в Windows, и в Linux |
| `pl2pl pyhpc` | Ускоряет вычисления на Python с помощью Numba |
| `pl2pl watch` | Находит новые версии языков и фреймворков и автоматически подстраивается (см. ниже) |
| `pl2pl llm setup` | Устанавливает ИИ-помощника (aruaru-llm) под ваш компьютер (реальная установка пока не проверена) |

## Автоматически следовать за новыми версиями
Запускайте `pl2pl watch` каждый вечер и каждое утро.
1. Он ищет новые версии языков и фреймворков (список — в `registry/ecosystem.toml`).
2. Проверяет на новой версии. Если тесты проходят, сам обновляет «поддерживаемую версию».
3. Если не проходят, version-control (с помощью ИИ) пытается исправить.
4. Если и это не помогло, отправляет сообщение на зарегистрированные адреса электронной почты и в LINE.

Скрипты для запуска по расписанию: `scripts/pl2pl-watch.cmd` (Windows) и `scripts/pl2pl-watch.sh` (Linux/Mac).
Примечание: для laravel, symfony, flask, django и других он пока лишь сообщает, что «вышла новая версия». Настоящие тесты на новых версиях ещё предстоит сделать.

## Примеры
```
pl2pl php ./myapp --out ./out
pl2pl web ./project --target fastapi --out ./out
```

## Обратите внимание
- pl2pl действует осторожно. Всё, что выглядит рискованным, остаётся без изменений, а причина объясняется. Скорость не гарантируется.
- Проверка шла только на небольших примерах, на больших настоящих программах — пока нет.

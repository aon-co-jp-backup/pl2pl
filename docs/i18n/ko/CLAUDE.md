# pl2pl CLAUDE
- **역할**: 언어·프레임워크·운영체제 사이의 변환 도구(`src/`의 Rust CLI). 변환 원본 후보는 `docs/LANGUAGES.md`, 조합은 `docs/COMBINATIONS.md`에 있습니다. 설계 사양은 소유자가 `docs/DESIGN.md`에 조금씩 적어 가므로, 소유자 대신 사양을 지어내지 마세요.
- **규칙**: 변환하지 못한 부분은 `TODO`로 남기고 보고서에 적습니다. 조용히 빼 버리지 마세요. 작업이 끝났다고 말하기 전에 실제로 실행해서 확인하세요. 판단은 보수적으로: 의존 관계나 부작용이 있을 수 있으면 변환하지 않습니다.
- **PHP**: `src/php.rs`, `src/blade.rs`, `src/middleware.rs`. 종단 간 시험은 `tests/run-php.sh`(실제 FastAPI, SQLite, Jinja2), 단위 시험은 `cargo test --release`. WSL에서 `wsl -d Ubuntu -- bash <스크립트 파일>`로 실행합니다.
- **주의할 점**: Windows에서 일본어가 들어간 파일은 Python의 `-X utf8`로 쓰세요. 셸 스크립트는 LF 줄바꿈을 유지하고, Git Bash는 `/mnt/...` 경로를 바꿔 버립니다.
- **COBOL_to / Java_to**: 다른 세션이 개발 중입니다. 나중에 합치고, 원래 저장소는 최종 확인을 받은 뒤에만 삭제하세요. 되돌릴 수 없습니다.
- **번역 시스템**(자연어)은 변환기와 분리해 둡니다.
- **문서 언어**: 루트에는 일본어, `docs/i18n/` 아래에는 아홉 개 언어(AI 번역, 원어민 검수 전)가 있습니다. 일본어 원문을 고치면 번역본도 함께 고쳐 주세요.
